**نرم‌افزار ویندوزی استخراج، تولید و ترجمه کاملاً محلی و آفلاین زیرنویس فیلم با هوش مصنوعی**

LocalSub یک نرم‌افزار حرفه‌ای، سریع و کاملاً آفلاین برای ویندوز ۱۰ و ۱۱ است که دیالوگ‌های انگلیسی فایل‌های ویدیویی را با استفاده از مدل‌های پیشرفته هوش مصنوعی (Whisper و NLLB-200) تشخیص داده و زیرنویس استاندارد SubRip (`.srt`) با زمان‌بندی دقیق میلی‌ثانیه‌ای به زبان **فارسی** یا **انگلیسی** (یا هم‌زمان هر دو) تولید می‌کند.

> 🌟 **بدون نیاز به نصب پایتون و بدون نیاز به کارت گرافیک مجزا (GPU):** تمام پردازش‌ها ۱۰۰٪ روی پردازنده معمولی (CPU) سیستم شما انجام می‌شوند و هیچ داده‌ای به هیچ سرور خارجی ارسال نمی‌شود.

## ویژگی‌های کلیدی

- 🔒 **۱۰۰٪ محلی، امن و خصوصی (Zero Cloud)**: هیچ صوت، تصویر یا متنی به اینترنت ارسال نمی‌شود. امنیت کامل حریم خصوصی برای تمام فایل‌ها تضمین شده است.
- ⚡ **استخراج صوت فوق‌العاده سریع (250x Real-time)**: جداسازی و تبدیل صدای ویدیو به سیگنال استاندارد هوش مصنوعی ظرف کمتر از ۲ ثانیه با استفاده از پردازش موازی FFmpeg.
- 🎯 **خروجی هم‌زمان فارسی و انگلیسی**: در حالت ترجمه فارسی، می‌توانید با فعال کردن یک تیک، هم‌زمان زیرنویس انگلیسی اصلی (`.en.srt`) و زیرنویس ترجمه‌شده فارسی (`.fa.srt`) را با زمان اضافه «صفر ثانیه» دریافت کنید.
- 🖥️ **بهینه‌سازی شده برای CPU (INT8)**: اجرای سبک و پرسرعت با موتور CTranslate2 با محاسبات کوانتایز شده بدون نیاز به کارت گرافیک مجزا.
- ⏱️ **زمان‌بندی میلی‌ثانیه‌ای دقیق**: همگام‌سازی کامل دیالوگ‌ها مطابق استاندارد SubRip (`HH:MM:SS,mmm`).
- ✍️ **اصلاح خودکار نگارش فارسی**: تصحیح خودکار حروف عربی (تبدیل «ي» و «ك» به «ی» و «ک») و نرمال‌سازی علائم نگارشی فارسی (`؟`، `،`، `؛`).
- 📦 **امکان وارد کردن فایل زیپ مدل‌ها**: دریافت لینک‌های دانلود برای دریافت با دانلود منیجر (IDM) و وارد کردن ساده فایل ZIP در برنامه.
- 🎬 **پشتیبانی از انواع فرمت‌های ویدیویی**: پشتیبانی از MP4, MKV, AVI, MOV, WMV, M4V, WEBM با قابلیت کشیدن و رها کردن (Drag & Drop) و اسکن پوشه.

## دانلود و اجرای نسخه آماده (بدون نیاز به پایتون)

اگر برنامه‌نویس نیستید و فقط می‌خواهید از نرم‌افزار استفاده کنید:

1. به بخش **[Releases](https://github.com/LocalSub/LocalSub/releases)** در همین مخزن بروید.
2. آخرین فایل فشرده با نام `LocalSub-v1.0.0-windows-x64.zip` را دانلود کنید.
3. فایل را از حالت فشرده خارج (Extract) کنید.
4. روی **`LocalSub.exe`** دو بار کلیک کنید تا برنامه باز شود!
   *(نیازی به نصب پایتون، درایور یا دستورات ترمینال نیست).*

## حالت‌های زیرنویس

در بالای پنجره برنامه از منوی **Subtitle Language** حالت مورد نظر خود را انتخاب کنید:

1. **Persian (فارسی - Local AI Translated) [پیش‌فرض]**:
   - گفتار انگلیسی توسط Whisper پیاده‌سازی شده و سپس با مدل عصبی NLLB به فارسی سلیس ترجمه می‌شود.
   - خروجی با نام `<نام_فیلم>.fa.srt` ذخیره می‌شود.
   - **گزینه ذخیره هم‌زمان انگلیسی:** با فعال بودن گزینه `Also save English .en.srt` در بخش تنظیمات، فایل اصلی انگلیسی نیز بدون هیچ زمان اضافه‌ای در کنار فایل فارسی ذخیره می‌شود.

2. **English (Original Speech Transcript)**:
   - گفتار انگلیسی بدون ترجمه مستقیماً پیاده‌سازی و زمان‌بندی می‌شود.
   - در این حالت مدل ترجمه اصلاً دانلود یا اجرا نمی‌شود تا رم و پردازنده به حداقل برسد.
   - خروجی با نام `<نام_فیلم>.en.srt` ذخیره می‌شود.

## مدل‌های هوش مصنوعی و منابع سیستم

### ۱. مدل‌های تشخیص گفتار (faster-whisper)
- **Base (~145 MB)**: فوق‌العاده سریع (سرعت ~7.6x زمان واقعی). یک فیلم ۷ دقیقه‌ای در کمتر از ۱ دقیقه پیاده‌سازی می‌شود.
- **Small (~488 MB) [پیش‌فرض و پیشنهادی]**: بالاترین تعادل بین دقت کلمات و سرعت روی پردازنده.
- **Medium (~1.5 GB)**: حداکثر دقت برای دیالوگ‌های سخت با همهمه یا موسیقی زیاد.

### ۲. مدل ترجمه انگلیسی به فارسی
- **Meta NLLB-200 Distilled 600M (پیشنهادی)**: نسخه فشرده INT8 مدل چندزبانه پیشرفته متا با مصرف رم حدود ۸۵۰ مگابایت و خروجی طبیعی فارسی.

## راهنمای دریافت و وارد کردن مدل‌ها

برای راحتی کاربران در دانلود مدل‌ها (به‌ویژه با اینترنت ناپایدار)، امکان دریافت لینک مستقیم و وارد کردن فایل زیپ در نرم‌افزار تعبیه شده است:

1. در برنامه روی دکمه **Download / Import...** در کنار مدل مربوطه کلیک کنید.
2. در پنجره بازشده:
   * می‌توانید روی **باز کردن صفحه دانلود در مرورگر** یا **کپی لینک مستقیم** کلیک کنید و فایل‌ها را با **IDM** دانلود نمایید.
3. پس از دانلود، فایل‌های مدل را در یک فایل ZIP قرار دهید (یا پوشه حاوی آن‌ها را نگه دارید).
4. دکمه **«انتخاب فایل ZIP مدل»** یا **«انتخاب پوشه»** را بزنید؛ نرم‌افزار به‌صورت خودکار فایل‌ها را استخراج و آماده به کار می‌کند و نشانگر وضعیت سبز و **Ready (Offline)** می‌شود.

## کامپایل و انتشار خودکار توسط GitHub Actions

این پروژه مجهز به گردش کار خودکار **GitHub Actions CI/CD** است. هر زمان یک تگ نسخه (مثلاً `v1.0.0`) در مخزن ثبت شود:

1. سرورهای ویندوزی گیت‌هاب پروژه را چک‌اوت می‌کنند.
2. آخرین نسخه ابزار FFmpeg را به صورت خودکار دریافت و ادغام می‌کنند.
3. تمام تست‌های خودکار (`pytest`) را اجرا می‌کنند.
4. با PyInstaller یک بسته کاملاً مستقل ویندوزی و فایل آرشیو ZIP همراه با چک‌سام SHA-256 می‌سازند.
5. فایل نهایی را به صورت خودکار در بخش **GitHub Releases** منتشر می‌کنند تا کاربران بدون نیاز به هیچ ابزاری آن را دانلود و اجرا کنند.

## اجرا و توسعه از روی سورس کد

اگر مایلید پروژه را از روی سورس کد پایتون توسعه دهید یا اجرا کنید:

```powershell
# 1. شبیه‌سازی مخزن
git clone https://github.com/LocalSub/LocalSub.git
cd LocalSub

# 2. ایجاد محیط مجازی پایتون 3.11
py -3.11 -m venv .venv
.\.venv\Scripts\activate

# 3. نصب وابستگی‌های توسعه
pip install --upgrade pip
pip install -r requirements-dev.txt

# 4. اجرای تست‌های خودکار
pytest -v

# 5. اجرای مستقیم نرم‌افزار
python -m app.main
```

### ساخت دستی فایل اجرایی ویندوز:
```powershell
python packaging/build_windows.py
```
خروجی در پوشه `dist/` ایجاد خواهد شد.

## مسیر ذخیره‌سازی فایل‌ها و لاگ‌ها

* **مدل‌های هوش مصنوعی:** `%LOCALAPPDATA%\LocalSub\models`
* **تنظیمات کاربر:** `%LOCALAPPDATA%\LocalSub\settings.json`
* **لاگ‌های برنامه:** `%LOCALAPPDATA%\LocalSub\logs\localsub.log`
* **فایل‌های موقت صوتی:** `%LOCALAPPDATA%\LocalSub\temp` (پس از اتمام کار بلافاصله پاک می‌شوند)
