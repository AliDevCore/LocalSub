### نرم‌افزار ویندوزی استخراج، تولید و ترجمه کاملاً محلی و آفلاین زیرنویس فیلم با هوش مصنوعی

نرم‌افزار **LocalSub** یک ابزار حرفه‌ای، پرسرعت و مستقل برای سیستم‌عامل ویندوز ۱۰ و ۱۱ است که گفتار انگلیسی ویدیوها را با مدل‌های پیشرفته هوش مصنوعی (Whisper و NLLB-200) شناسایی کرده و فایل زیرنویس استاندارد SubRip با پسوند (`.srt`) با زمان‌بندی دقیق میلی‌ثانیه‌ای را به زبان **فارسی** یا **انگلیسی** (یا هم‌زمان هر دو) استخراج می‌کند.

> 🌟 **بدون نیاز به کارت گرافیک مجزا (GPU) و پس از دریافت مدل‌ها ۱۰۰٪ آفلاین:**  
> تمام پردازش‌ها روی پردازنده معمولی سیستم (CPU) انجام می‌شوند و دیالوگ‌ها و فایل‌های صوتی شما به هیچ وجه از رایانه خارج نمی‌شوند. (دانلود اولیه وزن مدل‌ها از ریپازیتوری‌های رسمی Hugging Face انجام شده یا به صورت دستی با فایل ZIP وارد می‌شود).

## ویژگی‌های کلیدی

- 🔒 **حفظ کامل حریم خصوصی (Zero Data Leakage)**: بدون ارسال صوت، متن یا ویدیو به سرورهای ابری. امنیت کامل برای فیلم‌های شخصی، خانوادگی و پروژه‌های کاری.
- ⚡ **استخراج صوت بهینه با FFmpeg**: تفکیک مستقیم صوت استریو به سیگنال استاندارد هوش مصنوعی در چند ثانیه.
- 🎯 **تولید هم‌زمان زیرنویس انگلیسی و فارسی**: با انتخاب ترجمه فارسی و فعال کردن تیک مربوطه، فایل انگلیسی اصلی (`.en.srt`) و فارسی ترجمه‌شده (`.fa.srt`) به‌صورت هم‌زمان ذخیره می‌شوند.
- 🖥️ **بهینه‌سازی شده برای CPU معمولی (INT8)**: بر پایه موتور سریع CTranslate2 بدون نیاز به کارت گرافیک گران‌قیمت یا نصب درایورهای CUDA.
- ⏱️ **زمان‌بندی استاندارد SubRip**: تفکیک استاندارد هر خط به حداکثر ۴۲ کاراکتر، جلوگیری از همپوشانی بازه‌های زمانی و ذخیره‌سازی با کدگذاری UTF-8 BOM جهت سازگاری کامل با تمامی تلویزیون‌ها و پلیرها.
- ✍️ **اصلاح هوشمند نگارش و علائم فارسی**: تبدیل «ي» و «ك» به حروف فارسی بدون تغییر حروف خاص (مانند مؤمن یا مسأله) و بدون آسیب به لینک‌ها و عبارات انگلیسی.
- 📦 **دانلود مستقیم یا درون‌ریزی فایل ZIP مدل‌ها**: دریافت لینک‌های دانلود مستقیم برای استفاده در IDM و وارد کردن ساده فایل ZIP در برنامه.
- 🎬 **پشتیبانی وسیع فرمت‌ها**: پشتیبانی از MP4, MKV, AVI, MOV, WMV, M4V, WEBM, M2TS با قابلیت کشیدن و رها کردن (Drag & Drop).

## دانلود و اجرای نسخه آماده (بدون نیاز به پایتون)

اگر برنامه‌نویس نیستید و فقط مایلید از نرم‌افزار آماده استفاده کنید:

1. به بخش **[Releases](https://github.com/AliDevCore/LocalSub/releases)** بروید.
2. آخرین فایل فشرده با نام `LocalSub-v1.0.0-windows-x64.zip` را دانلود کنید.
3. فایل را از حالت فشرده خارج (Extract All) نمایید.
4. وارد پوشه شده و فایل **`LocalSub.exe`** را با دابل‌کلیک اجرا کنید!  

> 💡 **نکته امنیتی ویندوز (SmartScreen):**  
> از آنجا که این برنامه یک پروژه متن‌باز رایگان است و فاقد امضای دیجیتال تجاری چند هزار دلاری مایکروسافت می‌باشد، ممکن است ویندوز پیامی تحت عنوان Windows protected your PC نمایش دهد. برای اجرای برنامه کافی است روی گزینه **More info** و سپس **Run anyway** کلیک کنید. شما همواره می‌توانید کد هش SHA-256 فایل فشرده را با فایل پیوست اعتبارسنجی مقایسه نمایید.

## حالت‌های زیرنویس

در بالای پنجره برنامه از منوی **Subtitle Language** حالت مورد نظر خود را انتخاب نمایید:

1. **فارسی (Persian - Local AI Translated) [پیش‌فرض]**:
   - گفتار انگلیسی ویدیو توسط Whisper پیاده‌سازی شده و سپس با مدل NLLB-200 به فارسی روان ترجمه می‌شود (`.fa.srt`).
   - با تیک `Also save English .en.srt` نسخه انگلیسی نیز در کنار آن ذخیره می‌شود.

2. **انگلیسی (English - Original Speech Transcript)**:
   - دیالوگ‌های انگلیسی مستقیماً استخراج و با فرمت `.en.srt` ذخیره می‌گردند. در این حالت مدل ترجمه اصلاً فراخوانی نمی‌شود تا رم و CPU آزاد بماند.

## مدل‌های هوش مصنوعی و عملکرد سخت‌افزار

معیارهای سرعت اعلام‌شده بر روی پردازنده‌های استاندارد ۴ و ۶ هسته‌ای لپ‌تاپ و دسکتاپ (Intel Core i5 نسل ۱۰ به بعد / AMD Ryzen 5) اندازه‌گیری شده‌اند:

### ۱. مدل‌های تشخیص گفتار (faster-whisper)
- **Base (~145 MB)**: سرعت بالا (~7x سریع‌تر از زمان واقعی فیلم). مناسب دیالوگ‌های شفاف و ویدیوهای آموزشی.
- **Small (~488 MB) [پیش‌فرض و پیشنهادی]**: تعادل فوق‌العاده میان دقت بالای کلمات و سرعت بهینه بر روی CPU.
- **Medium (~1.5 GB)**: حداکثر دقت برای اصطلاحات پیچیده، فیلم‌هایی با همهمه، موسیقی و نویز پس‌زمینه.

### ۲. مدل‌های ترجمه انگلیسی به فارسی
- **Google TranslateGemma 4B [پیش‌فرض و پیشنهادی]**: مدل تخصصی و فوق‌العاده باکیفیت ترجمه شرکت گوگل (بر پایه Gemma 3 و تقطیر Gemini) با فرمت بهینه‌شده GGUF Q4_K_M (~۲.۴ گیگابایت). این مدل اصطلاحات روزمره، دیالوگ‌های عامیانه فیلم‌ها و دستور زبان طبیعی فارسی را با دقت بسیار بالا ترجمه می‌کند.
- **Meta NLLB-200 Distilled 600M [سبک با رم کم]**: نسخه فشرده INT8 مدل چندزبانه متا با مصرف حدود ۸۵۰ مگابایت رم برای سیستم‌های با سخت‌افزار بسیار محدود.

## راهنمای دریافت و وارد کردن مدل‌ها

1. روی دکمه **Download / Import...** در کنار مدل کلیک کنید.
2. با کلیک روی **Open in Browser** یا **Copy Direct Link** فایل‌ها را با دانلود منیجر (مثل IDM) دانلود نمایید.
3. فایل‌های دانلود شده را در قالب فایل ZIP قرار داده و با دکمه **انتخاب فایل ZIP مدل** درون برنامه بارگذاری کنید تا نشانگر وضعیت به **Ready (Offline)** تبدیل شود.

## کامپایل و انتشار خودکار توسط GitHub Actions

این مخزن دارای خط لوله خودکار **GitHub Actions CI/CD** است. با ثبت هر تگ نگارش (مانند `v1.0.0`):

1. سرور ویندوزی گیت‌هاب پروژه را بیلد می‌کند.
2. آزمون‌های خودکار کیفیت سنجی (`pytest`) و تست صحت باینری اجرایی (`--selftest`) سپری می‌شوند.
3. خروجی نهایی کامپایل شده همراه با چک‌سام SHA-256 در برگه **Releases** گیت‌هاب قرار می‌گیرد.

## اجرا و توسعه از روی سورس کد

اگر مایلید پروژه را از روی سورس پایتون ویرایش و اجرا کنید:

</div>

<div dir="ltr">

```powershell
# 1. شبیه‌سازی مخزن
git clone https://github.com/AliDevCore/LocalSub.git
cd LocalSub

# 2. ساخت محیط مجازی پایتون 3.11
py -3.11 -m venv .venv
.\.venv\Scripts\activate

# 3. نصب بسته‌های مورد نیاز
pip install --upgrade pip
pip install -r requirements-dev.txt

# 4. اجرای آزمون‌های خودکار
pytest -v

# 5. تست خودکار باینری
python -m app.main --selftest

# 6. اجرای مستقیم نرم‌افزار
python -m app.main
```

### ساخت پکیج اجرایی مستقل ویندوز:
```powershell
python packaging/build_windows.py
```

</div>

<div dir="rtl">

فایل خروجی و فایل آرشیو ZIP در پوشه `dist/` ساخته خواهد شد.

## مسیر ذخیره‌سازی فایل‌ها و لاگ‌ها

* **مدل‌های هوش مصنوعی:** `%LOCALAPPDATA%\LocalSub\models`
* **تنظیمات برنامه:** `%LOCALAPPDATA%\LocalSub\settings.json`
* **گزارش‌ها و لاگ‌ها:** `%LOCALAPPDATA%\LocalSub\logs\localsub.log`
* **فایل‌های موقت صوتی:** `%LOCALAPPDATA%\LocalSub\temp` (پس از اتمام کار بلافاصله حذف می‌شوند)
