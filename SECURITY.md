# Security and Privacy Policy

## 1. Privacy Guarantees

LocalSub was designed from the ground up with a strict **Privacy-First, Offline-First** philosophy:

- **100% Local Inference**: All speech recognition (Whisper) and neural machine translation (NLLB-200) execute directly on the user's local CPU.
- **No Cloud APIs**: Neither video files, extracted audio tracks, nor transcribed/translated dialogue are ever uploaded or transmitted to any external server or API.
- **Zero Telemetry**: LocalSub contains no telemetry, user tracking, or background metrics reporting.
- **Dialogue Privacy in Logs**: Application logs strictly exclude spoken dialogue or subtitle text. Logs only record technical operational data (timestamps, video container format, audio stream duration, model names, memory metrics, and stack traces).
- **Offline Capability**: Once models are downloaded, LocalSub operates completely without internet connectivity.

## 3. Reporting a Security Vulnerability

If you discover a security vulnerability in LocalSub, please report it responsibly to the project administrator.

Please include:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and suggested mitigations.

We will review and respond to reports within 48 hours.
